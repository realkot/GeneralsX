# GeneralsX r8 — изменения

- Панель перемещена к правому краю. Кнопки армии опущены в свободное пространство слева, «+» размещён над ними, группы 0–9 раскрываются выше.
- Максимальная ручная высота камеры ограничена 3600; обновлены подписи GeneralsX [mod by realkot].
- Экспериментальный массовый апскейл: 103 игровых UI-атласа и 14 изображений лаунчера. APK около 807 МиБ.
- **Архивный эксперимент:** результат апскейла отклонён пользователем; дополнительные 97 атласов и изображения лаунчера впоследствии возвращены в r9. Для текущих тестов рекомендуется r9.

Пакет: `com.generalsx.zerohour.inputtest`; версия `1.4.0-inputtest.20261015-r8` (10308). Android 9+, ARM64, движки 30/60 Гц; это частота симуляции, не гарантия FPS. Данные оригинальной игры нужно предоставить отдельно. Перед заменой установленной версии сохраните свои настройки и сохранения; Android может отклонить установку старого versionCode.
