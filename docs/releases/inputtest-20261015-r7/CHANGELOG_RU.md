# GeneralsX r7 — изменения

- Панель управления сохраняет исходные пропорции и располагается по центру; по бокам видна карта.
- Включены шесть HD-атласов панели США, Китая и ГЛА: локальный Real-ESRGAN x4 с сохранением прозрачности и логических координат.
- Физический курсор и его горячая точка увеличены вдвое; пропускается стартовый логотип EA.
- Исправлены опорные координаты повторного быстрого клика. Известная полоска высокой камеры остаётся неподтверждённо исправленной.

Пакет: `com.generalsx.zerohour.inputtest`; версия `1.4.0-inputtest.20261015-r7` (10307). Android 9+, ARM64, движки 30/60 Гц; это частота симуляции, не гарантия FPS. Данные оригинальной игры нужно предоставить отдельно. Перед заменой установленной версии сохраните свои настройки и сохранения; Android может отклонить установку старого versionCode.
