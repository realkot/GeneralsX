# GeneralsX r3 — изменения

- Пять кнопок армии расположены вертикально слева. Новая кнопка наземных боевых юнитов: экран → вся карта при повторном нажатии.
- Обычные приказы движения боевой группе используют атаку в движении; контекстные, специальные и принудительные команды сохраняют свои пути.
- Extras открывается как модальное окно поверх настроек: исправлены применение, отмена, закрытие и положение кнопки. Расширена ручная камера.
- Исправлены очереди событий мыши, первый приказ после выделения и пороги клика/перетаскивания на больших разрешениях.

Пакет: `com.generalsx.zerohour.inputtest`; версия `1.4.0-inputtest.20261015-r3` (10303). Android 9+, ARM64, движки 30/60 Гц; это частота симуляции, не гарантия FPS. Данные оригинальной игры нужно предоставить отдельно. Перед заменой установленной версии сохраните свои настройки и сохранения; Android может отклонить установку старого versionCode.
