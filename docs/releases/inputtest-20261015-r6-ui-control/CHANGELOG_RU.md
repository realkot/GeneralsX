# GeneralsX r6-ui-control — изменения

- Отдельная контрольная сборка для проверки более широких русских кнопок без новой нативной поправки GLES из финальной r6.
- Служит для сравнения интерфейса; не является следующим выпуском после r6. Имеет те же versionCode 10306 и versionName, что финальная r6, но другой SHA-256.
- Архивная диагностическая версия; для обычного тестирования используйте r9.

Пакет: `com.generalsx.zerohour.inputtest`; версия `1.4.0-inputtest.20261015-r6` (10306). Android 9+, ARM64, движки 30/60 Гц; это частота симуляции, не гарантия FPS. Данные оригинальной игры нужно предоставить отдельно. Перед заменой установленной версии сохраните свои настройки и сохранения; Android может отклонить установку старого versionCode.

Это публикация ранее собранного APK без пересборки. Тег архивной публикации указывает на текущий снимок исходников r9 и документацию; автоматически сформированный GitHub архив исходников не является точным деревом старой сборки. Для r9 опубликован соответствующий текущий снимок исходников.
