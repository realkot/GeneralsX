# GeneralsX r6 — изменения

- Кнопки армии расширены с 60 до 80 базовых пикселей для русских подписей; соседняя панель групп сдвинута.
- Изменено преобразование GLES ZBIAS в постоянное смещение глубины. Vulkan не менялся.
- Попытка не устранила подтверждённо полоску при высокой камере; этот графический эксперимент позднее отменён в r9.

Пакет: `com.generalsx.zerohour.inputtest`; версия `1.4.0-inputtest.20261015-r6` (10306). Android 9+, ARM64, движки 30/60 Гц; это частота симуляции, не гарантия FPS. Данные оригинальной игры нужно предоставить отдельно. Перед заменой установленной версии сохраните свои настройки и сохранения; Android может отклонить установку старого versionCode.
