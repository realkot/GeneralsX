# GeneralsX r5 — изменения

- Убраны маленькие квадратные маркеры с пяти шкал Extras во всех состояниях.
- Сохранены перетаскивание, клавиатурное управление, диапазоны и применение значений.
- Изменены только ресурсы: все 16 нативных библиотек, включая оба движка, побайтово совпадают с r4.

Пакет: `com.generalsx.zerohour.inputtest`; версия `1.4.0-inputtest.20261015-r5` (10305). Android 9+, ARM64, движки 30/60 Гц; это частота симуляции, не гарантия FPS. Данные оригинальной игры нужно предоставить отдельно. Перед заменой установленной версии сохраните свои настройки и сохранения; Android может отклонить установку старого versionCode.
